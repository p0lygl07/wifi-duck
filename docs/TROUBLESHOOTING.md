# WiFi Duck — Troubleshooting

### I can't see the WiFi network
Give it 10-15 seconds after plugging in. Make sure it has power. If you changed the SSID, look for your custom name.

### The web page won't load
Confirm your device is joined to the Duck's WiFi (no internet on it — that's normal). Use the gateway address from the WiFiDuck docs.

### It types too fast
Add `DELAY` lines, especially after `GUI r` and after launching apps.

### Default password still set
Change the AP password in the web UI. Don't run it on defaults around other networks.
